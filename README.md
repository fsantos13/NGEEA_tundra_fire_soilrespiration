# NGEEA_tundra_fire_soilrespiration
Datasets associated with manuscript on post-fire soil respiration and incubation study
Data creator and point of contact: Fernanda Santos, Oak Ridge National Laboratory
Contact: santosf@ornl.gov
Project: Next-Generation Ecosystem Experiments – Arctic
Project Director: Colleen Iversen
Some of the datasets in this repository are in ESS DIVE. The rest of the datasets are being submitted to ESS-DIVE.

This repository contains the following datasets

#(A)Soil respiration in 2023 (kfc_soilrespiration.csv)
#(B)Thaw depth (Thaw_depth_stats.csv)
#(C)Thaw depth and soil respiration (Thaw_depth.csv)
#(D)Soil respiration 2023-2024 (respiration_20232024.csv)
#(E)Organic layer (kfcdata.csv)
#(F)Incubation CO2 production rates (kfc_sr_incubation.csv)
#(G)Incubation Total (cumulative) CO2 production (kfc_sr_incubation_cum.csv)
#(H) Aqueous DOC (kfc_chem.csv)

This repository contains the following R code to make the figures and run statistical analysis: R_code_manuscript_txt

Location: Seward Peninsula of Alaska
